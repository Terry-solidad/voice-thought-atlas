# Voice Thought Atlas

1. A “second brain” for voice notes
Most people capture ideas by talking (in the car, on walks, in the shower) and then never revisit them. This app records voice memos, transcribes them, automatically tags and links related ideas, and resurfaces them at useful moments (“You mentioned this project three weeks ago, here’s what you said”). The value is in the resurfacing, not the capture. Monetize through a subscription for unlimited transcription and search.



**Live app**: https://voice-thought-atlas.lovable.app


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <https://github.com/Terry-solidad/voice-thought-atlas.git>
cd <repository-name>
npm install
npm run dev
```
